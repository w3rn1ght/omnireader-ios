# OmniReader для iOS 12 (jailbreak)

Универсальная читалка для устройств на **iOS 12 с джейлбрейком**. Открывает PDF, документы Office, электронные книги и комиксы, проигрывает аудиокниги, интегрирована с Яндекс Книгами (вход в аккаунт) и каталогами OPDS.

> Приложение не содержит контента, не обходит DRM и не является официальным клиентом Яндекса.

## Возможности

| Группа | Форматы |
| --- | --- |
| Книги | EPUB (2 и 3), FB2, FB2.zip, MOBI, AZW/AZW3 (без DRM), TXT, Markdown, HTML |
| Документы | PDF (PDFKit), DOCX, XLSX, PPTX (нативное извлечение текста), DOC/XLS/PPT (QuickLook), DjVu (текстовый слой) |
| Комиксы | CBZ; CBR — только если внутри ZIP |
| Аудио | MP3, M4A, M4B, AAC, FLAC, WAV, прямые ссылки на поток |
| Каталоги | OPDS 1.2 (Project Gutenberg, Calibre, Либрусек), школьные учебники so.11klasov.net, скачивание без входа |
| Сервисы | Яндекс Книги: OAuth / токен, полка, загрузка книг и аудио |

## Что нового в 1.4.6

- **Яндекс Книги — вход через сайт**: добавлена кнопка «Войти через сайт Яндекса» (WKWebView на `books.yandex.ru/my/books/all`). Это **единственный рабочий способ** получить доступ к личной полке («Мои книги»), потому что эндпоинт `p-graphql` отдаёт её только при наличии веб-сессии (Passport cookie). OAuth-токен по себе не работает — сервер отвечает `Whitelist: query not found`.
- Веб-сессия (cookie) сохраняется в Keychain и автоматически подставляется в запросы к `p-graphql`.
- OAuth оставлен как альтернатива для профиля/публичных полок, но с предупреждением, что личная полка через него не работает.
- Все колбэки ORHTTP теперь правильно диспатчятся на главный поток (исправлены возможные краши UI).
- Ошибка «Whitelist: query not found» теперь показывает понятное сообщение с предложением войти через сайт.
- **DjVu**: текстовый слой теперь официально поддерживается (ранее заявлено «не поддерживается» по ошибке).

## Что нового в 1.4.5

- **DjVu**: приложение разбирает контейнер и встроенный текстовый слой
  (`TXTz`/`TXTa`) и показывает книгу в обычной читалке. Сканы без распознавания
  не растрируются — для них открывается объяснение и кнопки «Открыть в другом
  приложении» / «Поделиться файлом»;
- **so.11klasov.net** добавлен как готовый каталог: классы, предметы, ОГЭ/ЕГЭ,
  обложки, постраничная навигация и локальный поиск по загруженной странице;
- **папки в библиотеке**: долгое нажатие на книгу → «Переместить в папку…»,
  отдельный список папок и «Скрытые»; скрытые книги не мешают в общем списке,
  но остаются в своей папке;
- **Яндекс Книги**: профиль ищется по нескольким именам корневого поля, затем
  через `login.yandex.ru`; ошибка объясняет, что OAuth-приложению нужен доступ
  к сервису «Книги»;
- **Либрусек/Флибуста**: для страницы `/b/<id>` прямые адреса загрузки
  (`?format=fb2.zip|epub|pdf|txt.zip`) пробуются первыми, глубина переходов
  через промежуточные страницы увеличена до 5.

## Что нового в 1.4.4

- скачивание из OPDS сначала идёт **анонимно**: сохранённый пароль больше не отправляется
  автоматически и не мешает открытым каталогам;
- логин и пароль применяются только как запасной вариант — после ответа `401`/`403`
  приложение один раз повторяет запрос с сохранёнными данными;
- исправлен повторный запрос с учётными данными: он больше не блокируется
  списком уже посещённых адресов;
- поведение Либрусека/Флибусты без входа не изменилось: прямые адреса
  `/b/<id>/download/?format=fb2.zip`, `?format=epub`, `Referer` и cookie сессии.

## Что нового в 1.4.3

- OPDS-каталоги больше не требуют логин: книги скачиваются анонимно, как у гостя сайта;
- загрузка подставляет `Referer` страницы книги, сохраняет cookie сессии и обходит
  промежуточные страницы «Скачать» (ищет ссылку в `<a>`, `window.open`, `location.replace`, `<meta refresh>`);
- для Либрусека/Флибусты автоматически пробуются прямые адреса `/b/<id>/download/?format=fb2.zip` и `?format=epub`;
- если запись каталога ведёт на страницу книги `/b/<id>`, приложение открывает её как промежуточную и находит файл;
- поля логина и пароля остались только для приватных серверов и полностью необязательны.

## Что нового в 1.1.0

- перелистывание вбок или вертикальная прокрутка (настройка и кнопка ↕ в ридере);
- аккуратная вёрстка с полями и висячим отступом абзаца, без наложения текста;
- скрываемый интерфейс: выход, поиск по тексту, закладки с заметками, быстрый переход по странице/проценту;
- OPDS: поиск по каталогу через OpenSearch, исправлено открытие разделов и HTTP-каталогов (ATS);
- EPUB: обложка берётся и из XHTML/SVG-страницы или самого крупного изображения;
- Яндекс: понятная реакция на вставку токена, проверка через login.yandex.ru, вход через Safari/ПК.

Читалка:

- постраничная вёрстка на CSS-колонках с плавным перелистыванием;
- темы: бумага, сепия, серый, ночь;
- шрифт, кегль, межстрочный интервал, отступы, выравнивание, переносы;
- оглавление, сохранение прогресса, слайдер страниц;
- озвучка текста голосом (AVSpeechSynthesizer) с любой страницы;
- PDF: непрерывный скролл, масштаб, оглавление по страницам, озвучка страницы;
- комиксы: свайпы, пинч-зум, ленивая загрузка страниц.

Аудиоплеер:

- фоновое воспроизведение и экран блокировки (Now Playing, пульт);
- таймер сна (5–60 минут), скорость 0.75×–3×, ±30 с;
- продолжение с места остановки, мини-плеер в библиотеке.

Библиотека: обложки (из EPUB/FB2/PDF/CBZ), поиск, фильтры, сортировка, импорт из «Файлов», открытие файлов из других приложений, удаление, шаринг.

## Требования

- iOS **12.0–12.5.7**, arm64, джейлбрейк (unc0ver / checkra1n / Chimera).
- Rootful-бутстрап (`iphoneos-arm`).
- Для сборки: macOS + Xcode, [Theos](https://theos.dev), SDK iPhoneOS 12.4, `ldid`, `xz`.

## Сборка

### GitHub Actions

Workflow `.github/workflows/build.yml` собирает `.deb` на `macos-15` с Xcode 16.2, Theos и SDK 12.4:

- push в `main` → артефакт `omnireader-deb`;
- тег `v*` → релиз с `.deb`.

### Локально

```sh
brew install ldid xz
export THEOS=$HOME/theos
git clone --recursive https://github.com/theos/theos.git "$THEOS"

git clone --depth=1 --filter=blob:none --sparse https://github.com/theos/sdks.git /tmp/theos-sdks
cd /tmp/theos-sdks && git sparse-checkout set iPhoneOS12.4.sdk
mkdir -p "$THEOS/sdks" && cp -R iPhoneOS12.4.sdk "$THEOS/sdks/"

cd omnireader
make package FINALPACKAGE=1
```

Пакет появится в `packages/`. LaunchScreen компилируется через `xcrun ibtool` (правило в `Makefile`).

## Установка

1. Скачайте `.deb` из артефактов/релизов.
2. Установите через **Sileo / Zebra / Filza** («Install from file»).
3. Или по SSH:

```sh
dpkg -i com.w3rn1ght.omnireader_1.4.4_iphoneos-arm.deb
uicache -p /Applications/OmniReader.app
```

Удаление: `dpkg -r com.w3rn1ght.omnireader`.

## Яндекс Книги

Подробности и ограничения — [Docs/YANDEX.md](Docs/YANDEX.md). Кратко:

- официального публичного API у Яндекс Книг нет; адаптер использует веб-эндпоинты и терпим к изменениям схемы;
- **вход через сайт (рекомендуется)**: нажмите «Войти через сайт Яндекса» — откроется `books.yandex.ru` внутри приложения. Войдите в аккаунт Яндекса обычным способом. Приложение сохранит Passport cookie, и **личная полка («Мои книги») станет доступна**. Это единственный способ прочитать полку, потому что эндпоинт `p-graphql` отдаёт её только при наличии веб-сессии (OAuth-токен по себе не работает — сервер отвечает `Whitelist: query not found`).
- OAuth (альтернатива, только профиль/публичные полки): в настройках укажите Client ID OAuth, затем «Войти по OAuth».
- если форма Яндекса на iOS 12 не реагирует на кнопки — «Войти через Safari» или вход на компьютере по скопированной ссылке, затем вставить callback-адрес целиком;
- DRM-файлы не расшифровываются — если сервис отдаёт защищённый файл, приложение сообщит об ошибке;
- всегда можно импортировать купленный файл вручную через «+» → «Импортировать файл».

## Ограничения

- CBR (RAR) не распаковывается: конвертируйте в CBZ.
- MOBI/AZW3: PalmDOC-сжатие; HUFF/CDIC и DRM — нет. Конвертация через Calibre решает.
- DOC/XLS/PPT (старый бинарный формат) открываются только QuickLook — извлечение текста для них не делается.
- Встроенный RAR, EPUB с тяжёлыми скриптами и фиксированной вёрсткой могут отображаться упрощённо.
- Приложение не подписано сертификатом Apple — ad-hoc подпись `ldid`, достаточная для джейлбрейка.

## Дисклеймер

Проект предоставляется «как есть». Все права на книги, документы и товарные знаки принадлежат их владельцам. Не используйте приложение для обхода DRM или нарушения условий сервисов.
