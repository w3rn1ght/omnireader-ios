# Каталоги OPDS

## Добавление

Настройки → «Каталоги OPDS» → «Добавить каталог». Нужен полный URL фида, например
`https://www.gutenberg.org/ebooks.opds/` или `http://lib.rus.ec/opds`.

## Каталоги с входом (HTTP Basic)

Часть каталогов закрывает и фиды, и файлы логином с паролем. Сервер отвечает
`401 Unauthorized` и заголовком `WWW-Authenticate: Basic`. Либрусек работает именно так:

```
$ curl -I http://lib.rus.ec/login/opds
HTTP/1.1 401 Unauthorized
WWW-Authenticate: Basic realm="LOGIN"
```

Порядок действий:

1. Откройте каталог. Если фид закрыт, приложение сразу предложит вход.
2. Введите логин и пароль **сайта каталога** (не Яндекса и не iCloud).
3. Нажмите «Войти и повторить» — приложение повторит запрос с заголовком
   `Authorization: Basic …` и сохранит пару для этого каталога.
4. Позже изменить данные можно в Настройки → «Каталоги OPDS» → имя каталога →
   «Логин и пароль». В строке каталога отображается сохранённый логин.

Пароль хранится в Keychain; на ad-hoc/ jailbreak-сборках без entitlements —
в контейнере приложения (см. `BUILD.md`).

## Если файл всё равно не скачивается

Некоторые каталоги не отдают файлы через OPDS даже после входа (лимиты,
подписка, защита от скачивания). В окне ошибки нажмите «Открыть в Safari»:
скачайте книгу в браузере, затем «Поделиться» → OmniReader или откройте файл
из «Файлов» — приложение зарегистрировано как обработчик книжных форматов.

Если сервер вернул HTML-страницу вместо файла, приложение больше не импортирует
её как книгу: показывается начало страницы и причина.

## Поиск

Используется OpenSearch-шаблон из фида (`rel="search"`), в том числе
нестандартный `?ask={searchTerms}`. Если шаблона нет, пробуются типовые
варианты `/search?q=`, `/searchopds?ask=` и `/opds/search?q=`.
