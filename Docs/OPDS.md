# Каталоги OPDS

## Добавление

Настройки → «Каталоги OPDS» → «Добавить каталог». Нужен полный URL фида, например
`https://www.gutenberg.org/ebooks.opds/` или `http://lib.rus.ec/opds`.

## Скачивание без входа

Каталоги открываются и книги скачиваются **анонимно** — логин не требуется.
Приложение сначала запрашивает файл без каких-либо учётных данных, как обычный
гость сайта:

- подставляет `Referer` страницы книги (многие серверы без него отдают 403);
- сохраняет cookie сессии между запросами;
- если сервер отвечает HTML-страницей («файл начнётся через секунду», кнопка
  «Скачать», антилич), находит настоящую ссылку в разметке и скриптах
  (`<a href>`, `window.open`, `location.replace`, `<meta refresh>`) и повторяет
  загрузку;
- для движка Либрусека/Флибусты сам пробует прямые адреса вида
  `/b/<id>/download/?format=fb2.zip` и `/b/<id>/download/?format=epub`.

Обычный сценарий: добавить `http://lib.rus.ec/opds`, открыть каталог, выбрать
книгу — файл скачается без логина и пароля.

## Необязательный вход (HTTP Basic)

Некоторым приватным серверам (Calibre с паролем, личные библиотеки) всё же нужен
HTTP Basic. Поля «Логин» и «Пароль» в настройках каталога остаются для этого
случая, но заполнять их не нужно: без них приложение работает как гость.

Если данные сохранены, они отправляются в заголовке `Authorization: Basic …`
только для этого каталога. Пароль хранится в Keychain; на ad-hoc/jailbreak-сборках
без entitlements — в контейнере приложения (см. `BUILD.md`).

## Если файл всё равно не скачивается

Некоторые каталоги не отдают файлы через OPDS (лимиты, подписка, защита от
скачивания). В окне ошибки нажмите «Открыть в Safari»:
скачайте книгу в браузере, затем «Поделиться» → OmniReader или откройте файл
из «Файлов» — приложение зарегистрировано как обработчик книжных форматов.

Если сервер вернул HTML-страницу вместо файла, приложение больше не импортирует
её как книгу: показывается начало страницы и причина.

## Поиск

Используется OpenSearch-шаблон из фида (`rel="search"`), в том числе
нестандартный `?ask={searchTerms}`. Если шаблона нет, пробуются типовые
варианты `/search?q=`, `/searchopds?ask=` и `/opds/search?q=`.
