# Правовая информация и ограничения

## Контент

OmniReader — программа для чтения файлов, которые вы уже имеете право открывать. Она не содержит книг, не ищет их и не обходит защиту.

## DRM

Приложение **не обходит DRM**: ни Adobe ADEPT, ни Amazon, ни Яндекс, ни Apple FairPlay. Если файл защищён, пользователь увидит сообщение об ошибке. Обход DRM в большинстве юрисдикций незаконен, а обход средствами приложения нарушал бы условия сервисов.

## Яндекс Книги

- API неофициальный и может измениться или быть закрыт в любой момент.
- Используйте только собственный аккаунт. Автоматизация доступа может нарушать пользовательское соглашение Яндекса — решение об использовании принимаете вы.
- Скачивание доступно только для того, что сервис отдаёт без DRM.
- Названия и товарные знаки принадлежат ООО «Яндекс».

## OPDS-каталоги

Поддерживаются только каталоги, которые сами публикуют свой OPDS-фид. Приложение не содержит встроенного списка «пиратских» библиотек; добавляйте каталоги, распространение книг из которых законно (например, Project Gutenberg, библиотека вашего Calibre).

## Лицензия кода

Код приложения можно распространять на условиях MIT. Используя его, вы принимаете, что авторы не несут ответственности за нарушения, совершённые с его помощью.

## Приватность

- Никакой телеметрии и аналитики.
- Сетевые запросы: только OPDS-каталоги, Яндекс Книги и загрузки по вашим ссылкам.
- Токен Яндекса хранится в Keychain. Пароли OPDS — тоже в Keychain, привязанными к ID каталога.
- Файлы и прогресс чтения не покидают устройство.

## Ограничения, о которых стоит знать

- CBR (RAR) не распаковывается; перепакуйте в CBZ.
- MOBI/AZW3: поддерживается PalmDOC, но не HUFF/CDIC и не DRM.
- Старые DOC/XLS/PPT открываются только через QuickLook.
- EPUB с фиксированной вёрсткой и сложными скриптами может отображаться упрощённо.
