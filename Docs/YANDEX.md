# Яндекс Книги в OmniReader

## Что это

Интеграция сделана как **адаптер к веб-эндпоинтам** сервиса `books.yandex.ru`. Официального публичного API Яндекс Книг нет, поэтому:

- список эндпоинтов сосредоточен в одном месте — `Sources/ORYandexAPI.m`, методы `+baseURL`, `+profilePath`, `+shelfPath`, `+itemPathFormat`;
- разбор JSON намеренно «терпимый»: проверяются несколько известных путей (`items`, `books`, `library`, `data`, `results`, `book`, `item`) и несколько вариантов названий полей;
- если сервис меняет схему, приложение не падает: полка покажет пустой список, а загрузка вернёт понятную ошибку. Сырой не-JSON ответ пишется в лог (`[OmniReader] Yandex non-JSON response`).

Если вы знаете актуальные пути/поля — поправьте `ORYandexAPI.m` (и, при необходимости, `+normaliseBookDictionary:`). Больше нигде менять ничего не нужно.

## Вход в аккаунт

Два способа:

1. **OAuth через браузер.** В «Настройки → Яндекс Книги → Client ID OAuth» укажите `client_id` приложения, зарегистрированного на [oauth.yandex.ru](https://oauth.yandex.ru). В качестве Redirect URI должно быть разрешено `omnireader://oauth`. Затем «Войти в аккаунт» — откроется системное окно авторизации (`ASWebAuthenticationSession`), токен сохранится в Keychain.
2. **Токен вручную.** «Настройки → Вставить токен» или кнопка в диалоге Client ID. Токен также попадает в Keychain (`kSecClassGenericPassword`, сервис `com.w3rn1ght.omnireader`, аккаунт `yandex.token`).

Выход удаляет токен из Keychain.

## Что делает приложение

- `GET /api/v1/me` — имя пользователя для статуса в настройках.
- `GET /api/v1/library` — полка (с фолбэком на `/api/library`).
- По тапу на книгу — поиск прямой ссылки (`download_url`, `file_url`, `url`, …) или запрос `/api/v1/library/{id}`.
- Если найден аудиофайл (`is_audio`, `audiobook`, `type: audio`) — поток отдаётся в `ORAudioPlayer` с заголовком `Authorization: OAuth <token>`; работает фон и экран блокировки.
- Книга скачивается во временный файл и импортируется в библиотеку (`source = yandex`, `remoteID` сохраняется).

## Ограничения и правовая позиция

- **DRM не обходится.** Сервис может отдавать защищённые файлы; приложение их не расшифровывает и сообщит об ошибке. Это сознательное ограничение.
- Использование неофициальных эндпоинтов может нарушать пользовательское соглашение Яндекса. Используйте только свой аккаунт и только для личного чтения купленного контента.
- Потоковые ссылки могут истекать; при ошибке 401/403 переавторизуйтесь.
- Для офлайн-доступа надёжнее скачать книгу через официальный сервис и добавить файл в библиотеку через «+» → «Импортировать файл».

## Отладка

```sh
# на устройстве
/var/mobile/Documents  # файлы через iTunes/Files
# логи приложения
idevicesyslog | grep OmniReader
```

Проверить токен можно вручную:

```sh
curl -H "Authorization: OAuth $TOKEN" https://books.yandex.ru/api/v1/library
```

Если этот запрос возвращает JSON — приложение покажет полку; если 404/401, скорректируйте пути в `ORYandexAPI.m`.
